# data-prep

Ham veriyi analiz ve modellemeden önce incelemek, temizlemek ve düzenlemek için kullandığım araçlar.

Asıl kod [dataset-analysis-toolset](dataset-analysis-toolset/) klasöründe. Kurulum ve kullanım orada anlatılıyor; en kısa yol:

```bash
cd dataset-analysis-toolset
pip install -r requirements.txt
python main.py
```

Bu komut numaralı bir menü açar. Menüden dosya incelenebilir, iki dosya karşılaştırılabilir, veri temizlenip kaydedilebilir, kurallarla doğrulanabilir ve SQL sorgularından özellik çıkarılabilir.
